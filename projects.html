Six Mini-Projects, Three Capstones

Reading a module doesn't make you an analyst — doing the work does. Each module below ends with a small, concrete deliverable that uses only what that module taught. The three capstones combine everything into the portfolio pieces you actually lead an interview with.

Mini-projects — one per module

Do each one right after finishing its module, while the skill is fresh. None of these need anything beyond what that module already taught.

Module 0

Reframe your resume

Goal
Prove the pivot is framing, not tools — before touching a single technical skill.
Steps
Pick 3 real bullets from your current resume. Rewrite each with the formula: [analytical verb] + [what was measured] + [tool/method] + [quantified result]. If you don't have a real number, estimate one honestly and mark it as an estimate — don't leave it blank.
Deliverable
A before/after list of 3 bullets, saved somewhere you'll actually use it on the Resume & Apply page later.
Module 1

Build a weekly channel report

Goal
The exact spreadsheet skill a Marketing Analyst does every single week.
Dataset
Kaggle — "Marketing Campaign Performance Dataset."
Steps
Clean it (fix blanks, standardize dates, remove duplicates). Build a pivot table: spend and conversions by channel and month. Add a second small sheet of made-up "target CPA" per channel, XLOOKUP it in, and flag any channel over target. Add one SUMIFS KPI cell and one combination chart (bars + a rate line).
Deliverable
A saved spreadsheet file with the pivot, the XLOOKUP flag column, and the chart.
Module 2

SQL audit — 8 business questions

Goal
Prove you can go from a plain-English business question to a working query without hand-holding — this is exactly what a technical screen tests.
Where
The live SQL runner already in Module 2 — no setup needed.
The 8 questions
  1. Which channel has the highest average order value?
  2. Which 3 customers have generated the most total revenue?
  3. How many distinct customers ordered in each month?
  4. Which country has the highest total revenue, and from how many customers?
  5. Find any customer who has never placed an order that shows a NULL country (data-quality check).
  6. What's the month-over-month revenue change for the "Paid Search" channel specifically?
  7. Which customers signed up but placed zero orders in their signup month (slow starters)?
  8. Using the order_items table, which single product appears in the most baskets?
Deliverable
A doc with each question, the query you wrote, the result, and one sentence on what a marketer should do with the answer.
Module 3

Rebuild one bad dashboard

Goal
Dashboard judgment is the actual skill being tested, not chart mechanics.
Steps
Find a dashboard online you think is genuinely bad (a public Tableau Public gallery entry, a screenshot from a "worst dashboards" blog post, or one from your current job). Identify what's wrong using this course's hierarchy (KPI tiles → trend → breakdown → detail table). Rebuild the single worst chart from it in Tableau Public or Power BI Desktop (both free), following the hierarchy properly, using this course's SQL output as sample data if you don't have the original.
Deliverable
A screenshot of the "before," a screenshot of your rebuild, and a 3-sentence written critique of what changed and why.
Module 4

UTM governance doc + one real GA4 finding

Goal
Prove you can think about tracking architecture before a launch, not just react to broken data after.
Steps
Write a one-page UTM naming convention doc for a hypothetical 3-channel launch (paid social, email, paid search) — casing rule, separator rule, a fixed list of allowed utm_medium values. Then open Google's public GA4 demo property ("Google Merchandise Store"), find the Explorations funnel report, and identify one real drop-off point.
Deliverable
The naming convention doc, plus a screenshot of the funnel with 2 sentences on what the drop-off suggests.
Module 5

A/B test read-out memo

Goal
The actual deliverable a marketing analyst produces after a test ends — a decision memo, not a stats homework answer.
Dataset
Kaggle — "Marketing A/B Testing" dataset.
Steps
Calculate each group's conversion rate. Run it through this course's significance calculator (or a chi-square function in Sheets) to get a z-score and p-value. Check whether the sample size was actually large enough using this course's sample-size calculator, retroactively.
Deliverable
A one-page memo: the result, whether it's significant, a ship/no-ship recommendation, and one caveat about the sample (size, duration, or representativeness).

The 3 capstone portfolio projects

These are the pieces that go on your resume and LinkedIn, and the ones you present in a case-study interview round. Build them in order — each is meant to take about 1–2 weeks alongside the module you're on, per the Roadmap.

Capstone 1 — Weeks 8–9

Customer Segmentation Analysis

Dataset
Kaggle — "Online Retail II" (UCI) or "Mall Customer Segmentation Data." Both are transaction/customer-level and messy enough to require real cleaning.
Build it with
Module 1 (cleaning, pivot exploration) + Module 2's RFM/NTILE technique (Advanced tier) for the actual scoring.
Steps
  1. Clean the raw data in Excel/Sheets — remove cancelled orders, fix blanks, standardize customer IDs.
  2. Load it into a SQL environment (or keep using this course's SQLite pattern with your own data) and compute Recency, Frequency, Monetary per customer.
  3. Score each with NTILE(4), exactly as taught in Module 2, and combine into segment codes.
  4. Visualize segment sizes and average value per segment in a simple bar chart.
  5. Write the narrative — this is the actual deliverable, not the query.
The narrative to write
"I identified that X% of customers drive Y% of revenue and recommend a retention campaign for the next-highest-value segment." That sentence is the deliverable — the SQL is how you earned the right to say it.
Publish it
A doc or a simple webpage with the segment chart, the RFM table, and the narrative. Link it from your resume.
Capstone 2 — Weeks 10–11

A/B Testing & Conversion Rate Optimization

Dataset
Kaggle — "Marketing A/B Testing" dataset, or the Google Merchandise Store's public BigQuery sample (GA4 event-level, free).
Build it with
Module 5 in full — significance calculator, sample-size calculator, the peeking/multiple-testing warnings.
Steps
  1. State the hypothesis and success metric before looking at results (Module 0's "so what" test, applied for real).
  2. Calculate conversion rate per group, run the significance test, and check it against a sample-size calculation done retroactively.
  3. Segment the result by device or another dimension — check whether the effect holds everywhere or is concentrated in one segment.
  4. Write the ship/no-ship recommendation with the confidence level and one caveat.
The narrative to write
"Variant B lifted conversion X points at 95% confidence; I'd recommend shipping it but flag that the sample under-represents mobile traffic." The caveat is what separates an analyst from someone who ran a formula.
Publish it
A one-page write-up with the numbers, the chart, and the recommendation — this is the mini-project from Module 5, extended into a full narrative.
Capstone 3 — Weeks 13–14 — lead with this one

Marketing Campaign ROI Dashboard

Dataset
Kaggle — "Marketing Campaign Performance Dataset," blended with a UTM-tagged funnel you construct yourself (or Google/Meta Ads' downloadable sample exports).
Build it with
Everything — Module 1 (cleaning), Module 2 (SQL aggregation), Module 3 (dashboard build), Module 4 (UTM/channel structure), Module 5 (CAC/ROAS/LTV).
Steps
  1. Aggregate spend, revenue, CAC, and ROAS by channel and month in SQL.
  2. Build a 3-view Tableau/Power BI dashboard following Module 3's hierarchy: KPI tiles → trend → channel breakdown → detail table.
  3. Add one filter (date range) and one annotation per view — the "so what," not just the number.
  4. Find the one non-obvious insight (e.g. a channel that looks cheap by CAC but has weak 90-day LTV) and lead the write-up with it.
The narrative to write
"Channel C looks cheapest by CAC but has the worst 90-day LTV — reallocating 15% of its budget to Channel A would improve blended ROAS." This is the project you self-assigned and completed like the actual job.
Publish it
A published/embedded dashboard (Tableau Public is free and public by default) plus the write-up. This is the project you open with in a case-study interview round.

Once Capstones 1 and 2 are published and your resume is rewritten (around week 12), you're ready to start applying per the Roadmap — Capstone 3 finishes in parallel with your first applications, not before them.
