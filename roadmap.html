Roadmap

The 16-Week Plan, Visually

Four tracks running in parallel: learning, portfolio building, applying, and interview prep. They overlap on purpose — you don't wait until everything is "done" to start applying.

Timeline at a glance

The one rule that matters most

Applications start in week 12 — not after every module is finished. Portfolio Projects 1 and 2 plus a rewritten resume are enough to start getting screens while you finish Module 5 and Project 3 in parallel. Waiting for "fully ready" costs weeks you don't get back.

On the Beginner → Intermediate → Advanced structure

Every module now runs three tiers. On your first pass through weeks 1–14, Beginner + Intermediate per module is the real bar — that's what a 2-years-experience Marketing Analyst is expected to know cold. Advanced tiers (cohort SQL, attribution edge cases, regression/incrementality) are what turns a good answer into a standout one; keep circling back to them through weeks 15–16 and into your first months on the job. Check the Interview Bank for exactly which tier each real question tests.

Milestones — check them off as you go

This checklist is the second ring of progress on the home page, alongside modules and the resume checklist.

Week-by-week detail

Weeks 1–3
Foundations: Module 0 + Module 1
Learn the vocabulary shift and rebuild 3 reports you currently get from someone else, yourself, using pivot tables and XLOOKUP.
Weeks 4–7
SQL fluency — Module 2
Daily practice: SQLBolt → Mode → StrataScratch. By week 7, write a JOIN + GROUP BY + window function unassisted.
Weeks 8–9
Portfolio Project 1 — Customer Segmentation
Built in SQL + Sheets on the Kaggle "Online Retail II" or "Mall Customer Segmentation" dataset. Publish with a written narrative, not just charts.
Weeks 10–11
Module 3 (Dataviz) + Portfolio Project 2 — A/B Test & CRO
Learn Tableau/Power BI while building the second project, so the tool is applied immediately.
Week 12
Module 4 (GA4/GTM) + resume & LinkedIn overhaul
Rewrite the resume with the bullet formula on the Resume & Apply page. Applications begin this week.
Weeks 13–14
Module 5 (Metrics & Testing) + Portfolio Project 3 — ROI Dashboard
The capstone — the project you screen-share in interviews. Applications continue in parallel.
Weeks 15–16
Interview-ready: mock interviews, case drills, outreach ramp-up
Week-12 applications should be converting to screens by now. Keep applying — this doesn't stop at week 16.
