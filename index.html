How to use this

Every module teaches from zero, with diagrams, a quiz, and one interactive tool built for that specific skill (a live SQL editor in Module 2, a UTM builder in Module 4, a stats calculator in Module 5). Mark a module complete once you've run its tool and passed its quiz, then do that module's mini-project before moving on — reading alone won't make this stick. Check off Roadmap milestones as you hit them, and work the Resume & Apply checklist in parallel from around week 12 — the ring above combines all four.
